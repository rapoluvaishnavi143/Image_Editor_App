# 🖼️ Image Editing App using Streamlit & OpenCV
## 📌 Project Description
This project is a web-based Image Editing Application built using Python. It allows users to upload an image, apply different filters such as blur, brightness, contrast, sharpness, grayscale, and edge detection, and preview the changes in real time. The application is developed using Streamlit for the user interface and OpenCV for image processing. Users can also download the edited image after applying the desired filters.

## 🚀 Features

- Upload images in JPG, JPEG, and PNG formats  
- Apply Gaussian Blur filter with adjustable intensity  
- Adjust image Brightness using a slider  
- Adjust image Contrast using a slider  
- Enhance Sharpness of the image  
- Convert image to Grayscale  
- Detect edges using Canny Edge Detection  
- Apply multiple filters in sequence (stackable filters)  
- Real-time preview of original and processed images  
- Side-by-side comparison of images  
- Download the edited image as a PNG file  
- Simple and interactive user interface using Streamlit  

## 🛠️ Technologies Used

- **Python**  
  Core programming language used to build the application logic.

- **Streamlit**  
  Used to create the web-based user interface with components like buttons, sliders, file uploader, and image display.

- **OpenCV (cv2)**  
  Used for performing image processing operations such as blurring, sharpening, brightness/contrast adjustment, grayscale conversion, and edge detection.

- **NumPy**  
  Used for handling images as numerical arrays and performing efficient mathematical operations.

- **Pillow (PIL)**  
  Used to open, read, and handle image files uploaded by the user.
